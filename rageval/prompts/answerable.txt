Task: answerable

You check a question against evidence quotes. Answer from the quotes alone, not from your own knowledge.

Question as the user types it:
$question

Question rewritten so that it can be understood on its own:
$resolved_question

Gold key points:
$key_points

Evidence quotes:
$quotes

Definitions:
- Standalone: A person who has not seen the document or any earlier turn knows what is being asked. "What does the author conclude in section 3?" is not standalone.
- Key point: One statement that can be judged true or false on its own.

Do these steps:
1. "question_standalone": is the question as the user types it standalone?
2. "resolved_standalone": is the rewritten question standalone?
3. "answer": answer the rewritten question using only the quotes.
4. "key_points_covered": for each gold key point, in order, true if your answer states that fact, else false.
5. "quotes_used": for each quote, in order, true if you needed it to give your answer, else false.

Return JSON only, in exactly this shape:
{"question_standalone": true, "resolved_standalone": true, "answer": "...", "key_points_covered": [true], "quotes_used": [true]}
